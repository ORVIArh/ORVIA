# ORVIA brand assets

The repository banner uses the selected ORVIA Molecular O identity: seven atom nodes, an open top, and two inset double-bond strokes, in champagne gold on black.

- `orvia-banner.png` — the existing ORVIA gold banner, reused without changes.
- `research-flow.svg` — a schematic of the intended research workflow, not a record of a completed experiment.

The banner was created with the built-in image-generation tool on 2 November 2026. It is brand artwork, not a molecular structure or scientific result. Keep the symbol geometry and generous spacing intact when reusing it.
