# Production gap review

**The current source does not execute ORVIA-001 from prepared molecular inputs through a sampled binding-free-energy result. It is not ready for that mainnet launch.** This conclusion follows from missing input systems, incompatible capacity limits, separate simulation paths and the absence of a production simulation-to-analysis writer. A passing component suite or deployment of 50–64 instances cannot close those gaps.

This review inspected the current contracts, protocol, candidate data, independent references and recorded deployment evidence on 2026-11-01. It is a capability review, not a replacement for the final source-pinned test report. Scientific preparation, executable integration, validation and operator/network evidence are separate categories below.

## What actually runs today

| Path | Implemented scope | Boundary relevant to ORVIA-001 |
|---|---|---|
| `PeriodicMinimizer` | Bounded steepest descent/Armijo minimization of the cutoff Hamiltonian | No Ewald or constrained minimization; no trusted transition into a dynamics run |
| `LangevinDynamicsCoordinator` | BAOAB, deterministic counter noise, neighbor list, cutoff forces | No constraints, Ewald, alchemical state or production sample collection |
| `ConstrainedDynamicsCoordinator` | Neighbor list, cutoff forces, velocity Verlet with SHAKE/RATTLE | NVE; no thermostat, Ewald or alchemical state |
| `EwaldDynamicsCoordinator` | Bonded/LJ forces plus complete finite Ewald evaluation and NVE Verlet | No thermostat, constraints, neighbor-list electrostatic pass or alchemical state |
| `SoftcoreLennardJonesKernel`, `MonteCarloAcceptance` | Tested scalar pair soft-core and acceptance calculations | No live lambda Hamiltonian, exchange or volume-move coordinator |
| Collector → MBAR → diagnostics → repeat result | On-chain matrix analysis, overlap/weight checks and paired-repeat mean/SEM | Tests use synthetic writer inputs; no production molecular writer supplies the matrices |
| `TimeSeriesDiagnostics` | One-observable finite-window correlation calculation | Not integrated into production equilibration/selection or MBAR acceptance |

These distinctions are visible in imports and call sites, not inferred from contract names. In particular, no current dynamics coordinator calls `ReducedPotentialCollector.appendSample`, `TimeSeriesDiagnostics.append`, or the soft-core/exchange primitives.

NPT pressure control, replica exchange and PME are **conditional choices**, not universal requirements. If NPT is selected, a complete reversible volume proposal, scaling measure, energy evaluation, acceptance and rejection restoration are required; the acceptance kernel alone is insufficient. A fixed-volume protocol can omit a barostat when the scientific model justifies that ensemble.

These references do not select ORVIA's force field, numerical tolerances or sampling duration.

## Constrained-coordinate review

`ConstrainedDynamicsCoordinator._checkImage` enforces each constrained raw displacement component strictly inside the corresponding half-box interval at initialization, old/trial upload and completed position projection. Within this domain its direct SHAKE vectors agree with the force model's unique nearest image. `_applySolution` reconstructs the intermediate velocity as `(projected_position-old_position)/dt`; forces are recomputed at projected positions, the final kick is applied, and RATTLE precedes the atomic buffer commit. This ordering agrees with the independently derived oracle.

The coordinate convention is intentionally restrictive: molecules must already be consistently unwrapped; there is no molecule graph, winding-number tracking or repair of separately wrapped atoms. Long unwrapped translations can amplify finite-precision subtraction in reconstructed velocities. Production preparation must establish the supported image/coordinate domain, and production tests must cover whole-molecule lattice translations, actual constrained molecular geometries, nonzero charged/LJ interactions, timestep refinement and failure preservation. A generalized periodic-image solver is required only if the selected workload leaves this restricted domain.

`reference/constrained_trajectory.py` is an adequate independent ordering/force check for its three-atom, two-step fixture: simultaneous nonlinear position multipliers and dense mass-weighted velocity projection differ from the contract's sequential corrections. It checks residuals, momentum and ballistic center of mass as well as 84 state scalars. It does not validate a water force field, constrained thermostat, Ewald composition or production ensemble. The [OpenMM integrator reference](https://docs.openmm.org/latest/userguide/theory/04_integrators.html) also illustrates why velocity time conventions and ensemble-specific integration must be declared rather than inferred from an integrator name.
